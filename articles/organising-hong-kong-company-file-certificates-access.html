Organising a Hong Kong company file: certificates, versions and access

A good company folder lets you find the correct record quickly without exposing private information. The three real photographs in this carousel show the paperwork; the workflow below explains how to manage it.

Separate certificates from working copies

Keep issued certificates in a clearly marked folder. Store submitted applications and drafts separately. Label each file by document type, company and date so a draft cannot be mistaken for an issued record.

Track current and historical versions

Keep the previous version when details change, but clearly mark the current one. Avoid several files called final. A short index should show which certificate or record is being used and when it was last checked.

Control who sees personal information

Use access permissions and share only the documents needed for a request. Keep a redacted copy for general presentation. The public carousel has masked client details and must not be treated as an application template.

Prepare a request-specific bundle

Read the provider's checklist and select the relevant documents. Add a simple contents page when several files are requested. Keep a copy of what was sent and the date, so later questions can be answered consistently.

A document index you can maintain

Type
Name the record and its purpose.
Version
Record the date and distinguish current from historical.
Location
Identify the secure source file or physical record.
Access
Record who needs the document for which task.

Check the recipient’s request before sharing a bundle. A redacted public illustration, an application draft and an issued certificate should never be treated as interchangeable. Keep the full working record securely and share the minimum relevant information. If a record appears inconsistent, ask how to correct the underlying information rather than editing an official document to make it look right.

Frequently asked questions

Should I keep the green company kit?

Keep physical records safely if supplied, but also maintain a secure organised digital index.

Can I publish my company documents online?

Review personal and sensitive information first; public illustrations should use properly redacted copies.
